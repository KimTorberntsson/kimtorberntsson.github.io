Hello again!

Some time has passed since I was last here. Seven years, in fact. A lot has happened in my life since then. Houses have been bought, the family has multiplied etc. More on that later hopefully. The plan is to blog a bit during my current paternity leave with Tage, upload some photos etc.

This post though is about some changes to the site itself. With the help of our new robot friends I finally gave it the overhaul it has needed for a while. The goal was to fix some things that have been pretty rough, if I'm being honest. A 4.0 so to speak.

<img src="/assets/pictures/claude.png" alt="The Claude logo" width="120" height="120" />

We did a few larger changes and a lot of smaller tweaks. Here are the main ones, for the one person in the world who cares about any of this (that would be me 😀):

* Split into a latest posts page and an archive
* Grouped the archive by year
* A new photo viewer, with swiping and zooming on your phone
* Links to the older and newer post at the bottom of each post
* A page explaining how to subscribe, instead of raw XML
* A hero banner instead of a full screen photo you scroll past
* The post title now sits on the hero photo
* The hero photo fades in instead of flashing
* Lazy image loading, so pages start a lot faster
* Re-exported the photos, halving the size of the whole library
* Threw out jQuery, 94 KB blocking every page from rendering
* Optimised the whole site for touch and mobile
* Better contrast, bigger tap targets and accessibility fixes
* A proper 404 page, instead of the default GitHub one
* A copyright line with the year in the footer
